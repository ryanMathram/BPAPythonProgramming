# BPA Python Programming
This repository showcases a collection of Python projects developed for the Business Professionals of America (BPA) conferences, including the Regional State Leadership Conference in San Antonio and State Leadership Conferences in Dallas and Corpus Christi.

🏆 About the Project

The projects within this repository were created to demonstrate proficiency in Python programming and problem-solving skills in a competitive environment. Each project reflects the challenges and objectives presented during the BPA conferences, aiming to solve real-world problems through code.

Qualified to the National Leadership Conference in Orlando, Florida through the SLC Dallas.
1x National Qualifier
2x State Qualifier
2x Regional 1st Place

📁 Repository Structure

The repository is organized into directories corresponding to each conference event:
	•	CorpusChristiSLC2024/
	•	DallasSLC2025/
	•	Regional2025/

Each directory contains Python scripts and related resources specific to the projects developed for that particular event. 

🧰 Technologies Used
	•	Python 3.x ￼

Additional libraries and dependencies, if any, are documented within each project’s directory.

🪖 Challanges Faced

Also you go through the different types of competition stages, you have to find a way to evolve your technical and soft skills such as object oriented, data collection, time management, product view, etc.
